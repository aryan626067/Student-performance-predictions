Project Overview

Objective: To identify and predict key factors affecting student performance using machine learning classifiers.

Dataset: A CSV file (AI-Data.csv) comprising data on students from diverse nationalities and grade levels. Features include:

Number of hands raised

Number of attendances

Number of hours studied

And other relevant attributes

Implementation: The core logic is implemented in Project.py, where various classifiers are applied to the dataset to determine the most significant factors influencing student grades.

Visualization: The project includes visual aids such as graphs and confusion matrices to illustrate the results and performance of the models.​

🛠️ Technical Details
Language: Python

Machine Learning Techniques: Multiple classification algorithms are employed to analyze the dataset and predict outcomes.

Data Handling: The project reads and processes data from a CSV file, performing necessary preprocessing steps before model training.​
